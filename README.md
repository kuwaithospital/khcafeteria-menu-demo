# Kuwait Hospital · Patient Meal Ordering (Demo)

Interactive prototype for testing and management review. Patients, orders and accounts are fictitious, and nothing is connected to hospital systems.

## Publish with GitHub Pages

1. Create a new repository, for example `kh-meal-ordering-demo`.
2. Upload every file in this folder, including the `assets` folder, to the main branch.
3. Go to **Settings → Pages**. Set **Source** to *Deploy from a branch*, choose **main** and **/ (root)**, then press **Save**.
4. After about a minute the site is live at `https://<your-github-username>.github.io/kh-meal-ordering-demo/`.

A free GitHub account can only run Pages from a **public** repository, which means anyone with the link can open it. The start page asks search engines not to list it.
